# 工科数学分析基础（上册）自学站

面向大一学生的《工科数学分析基础》（第三版·上册，王绵森、马知恩主编，高等教育出版社）自学网页。

## 如何使用

- 本地学习：双击 `index.html`，完全离线可用（公式库 KaTeX 已内置）。
- 在线访问：本仓库已开启 GitHub Pages，网址为 <https://fsyiyu.github.io/math-analysis-web/>。

## 目录结构

- `index.html` —— 首页（学习地图 + 逐章课表）
- `ch1.html` ~ `ch4.html` —— 各章章页；第一、二、三章章页末尾附「章节思维导图」（可点击跳转）
- `lessons/` —— 绪论、第一章（1.1–1.5）、第二章（2.1–2.6）与第三章（3.1–3.5）的课页
- `exercises/` —— 章末练习页（第 1、2、3 章各 16 题可作答，第四章占位）
- `assets/` —— 共享样式、交互脚本与本地 KaTeX 公式库

## 内容说明

页面文字为原创学习笔记与数学学科通行表述，不是教材扫描件或原文搬运；
如需对照原书，请按“章·节”编号查阅纸质书或本地 PDF。
